# Space Portfolio

Static Next.js (`output: 'export'`) portfolio. Six stations flown through with CSS scroll-driven animations; falls back to a plain vertical layout.

- Edit content only in `content/site.json` (search `PLACEHOLDER`).
- `npm run build` -> `out/`
- `npm test` (needs a build + Chromium) runs the headless Must checks.
- `npm run lighthouse` runs Lighthouse (performance + accessibility).
- `npm run placeholders` writes `PLACEHOLDERS.md`.
